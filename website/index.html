Methodology & Workflow

An End-to-End Latent Architecture

Designed from first principles to process messy ocean buoy telemetry into verified, stable macro regimes without data leakage.

Station-Wise Circular Resampling

Telemetry arrives at irregular intervals. We resample each buoy station to 1-hour intervals. While numeric scalars use arithmetic mean, directional variables (Wind, Wave, Swell direction) utilize circular mathematics to avoid 0°/360° phase discontinuities.

Circular mean: atan2(mean(sin θ), mean(cos θ))
Continuous sinusoidal projections: DIR_SIN & DIR_COS 
# src/data/ingest.py
for dcol in directional_columns:
    rad = np.deg2rad(station_df[dcol])
    sin_avg = np.sin(rad).resample(rule).mean()
    cos_avg = np.cos(rad).resample(rule).mean()
    out[dcol] = (np.rad2deg(np.arctan2(sin_avg, cos_avg)) + 360) % 360

Quality Control & Gap Interpolation

Special missing sentinels (99, 999, 9999) are mapped to NaN. Small sensor drops (≤2h) are forward/backward filled, while medium gaps (≤6h) receive bounded linear interpolation. Outlier spikes are clamped within the 0.5% and 99.5% quantiles.

Zero lookahead bias during interpolation
Quantile bounds logged to quality_report.json 
# src/data/preprocess.py
working[cols] = working[cols].replace([99, 999, 9999], np.nan)
# Short gap forward/backward fill
g[numeric] = g[numeric].ffill(limit=2).bfill(limit=2)
# Medium gap bounded linear interpolation
g[numeric] = g[numeric].interpolate(method="linear", limit=6)

Multi-Scale Past-Only Windows

Marine dynamics operate across multiple time horizons. We extract statistics over 6-hour (immediate gusts), 24-hour (diurnal cycle), and 72-hour (synoptic weather fronts) rolling windows with regular strides.

6 features per scale: Mean, Std, Trend, Energy, Max, Min
Output dimension: 288 statistical features per window 
# src/features/window_engine.py
trend = window[-1] - window[0]
energy = np.sum(window**2, axis=0) / len(window)
stats = np.concatenate([
    window.mean(axis=0), window.std(axis=0),
    trend, energy, window.max(axis=0), window.min(axis=0)
])

A 3-layer PyTorch encoder compresses the 288-dimensional statistical representation into a smooth 32-dimensional latent manifold, denoising sensor measurement noise and isolating true atmospheric variance.

Hidden Markov Model (HMM)

Unlike static clustering (KMeans, GMM), Gaussian HMM with diagonal covariance models temporal transitions between ocean states. Optimal state count is selected by minimizing the Bayesian Information Criterion (BIC).

BIC Approximation: -2 ln L + (K² + 2Kd) ln N
Anti-flicker smoothing removes sub-threshold noise 
# src/models/hmm_model.py
model = GaussianHMM(
    n_components=n, covariance_type="diag", n_iter=300
)
model.fit(latent_embeddings)
logL = model.score(latent_embeddings)
bic = -2 * logL + (n**2 + 2*n*d) * np.log(n_samples)
